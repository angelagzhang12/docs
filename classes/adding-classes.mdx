Adding your courses to ClassTrack at the start of each semester gives the app everything it needs to build your schedule, send you reminders, and track your grades automatically. You can add as many classes as your semester requires and update any detail at any time if your course information changes.

## Adding a class

<Steps>
  <Step title="Open the Add Class screen">
    Navigate to the **Classes** tab and tap or click **+ Add Class** in the top-right corner of the screen.
  </Step>
  <Step title="Enter the class details">
    Fill in the core information for your course:
    - **Class name** — enter the full course title (e.g., "Calculus II")
    - **Instructor name** — the professor or teacher leading the course
    - **Credit hours** — the number of academic credits the course is worth
    - **Course code** *(optional)* — the departmental code for the class (e.g., "MATH 2420")
  </Step>
  <Step title="Set the class schedule">
    Define when and where your class meets:
    - Select the **meeting days** (e.g., Mon / Wed / Fri or Tue / Thu)
    - Choose the **start time** and **end time** for each session
    - Enter a **room or location** *(optional)*, such as a building name and room number
  </Step>
  <Step title="Choose a color label">
    Pick a color for the class from the color palette. This color will appear on every class card, calendar block, and assignment tied to this course, making it easy to identify at a glance.
  </Step>
  <Step title="Save the class">
    Tap **Save**. The class immediately appears in your Classes list and populates your schedule with all of its recurring meeting times.
  </Step>
</Steps>

## Editing a class

You can update any class detail at any time — for example, if your instructor changes a meeting room or you need to correct the credit hours.

<Steps>
  <Step title="Open the class">
    Tap the class card on your Classes screen to open the full class view.
  </Step>
  <Step title="Tap Edit">
    Tap the **Edit** button (pencil icon) in the top-right corner of the class page.
  </Step>
  <Step title="Make your changes">
    Update any fields you need to change, including the schedule, instructor, color, or course code.
  </Step>
  <Step title="Save your changes">
    Tap **Save**. Your updates take effect immediately across your schedule and class cards.
  </Step>
</Steps>

## Removing a class

If you drop a course or no longer need it in ClassTrack, you have two options: **archive** or **permanently delete**.

- **Archive** — removes the class from your active semester view but keeps all of its assignments, grades, and history intact. You can still access an archived class by switching to its semester in the semester switcher.
- **Delete** — permanently removes the class and all associated data.

To archive or delete a class, open the class, tap **Edit**, and scroll to the bottom of the edit screen to find the **Archive Class** or **Delete Class** option.

<Warning>
  Permanently deleting a class cannot be undone. All assignments, grades, and notes associated with that class will be removed forever. If you think you might need the data later, choose **Archive** instead.
</Warning>

## Class fields reference

| Field | Description | Required |
|---|---|---|
| Class Name | The full title of the course (e.g., "Intro to Psychology") | Yes |
| Instructor | The name of the professor or teacher for the course | Yes |
| Credit Hours | The number of academic credits the class is worth | Yes |
| Course Code | The departmental identifier for the course (e.g., "PSYC 1010") | No |
| Meeting Days | The days of the week the class meets (e.g., Mon / Wed / Fri) | Yes |
| Meeting Time | The start and end time for each class session | Yes |
| Location | The room number or building where the class is held | No |
| Color | A color label used to visually identify the class throughout the app | Yes |

<Note>
  You can add up to **20 classes per semester** in ClassTrack. If you need to track additional courses beyond that limit, consider whether any classes can be consolidated or archived from a previous term.
</Note>
